# Failure and recovery

An injected async loader uses a local fixture only. Submitting `fail` reaches the explicit `error` state; enter a valid topic and submit again to reach `ready` with data in the same page session. Blank input is validated before a request starts.

Open `index.html` locally. Browser check:

```sh
node 18_Day_Promises/applied-labs/r54-t045/check.mjs
```
